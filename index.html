요약

1. 수집하는 개인정보

현재 Muslim Korea는 개발자 서버를 통해 사용자 개인정보를 수집하거나 저장하지 않습니다. 사용자 계정, 회원가입, 로그인 기능도 제공하지 않습니다.

2. 위치정보

사용자가 현재 위치 사용을 선택하면 앱은 정확한 위치 또는 대략적인 위치에 대한 포그라운드 권한을 요청할 수 있습니다. 위치정보는 기도시간 계산, 시간대 선택, 가까운 도시 데이터 확인 및 키블라 방향 계산을 위해 기기 내부에서만 사용됩니다.

현재 Android 버전은 백그라운드 위치 권한을 요청하지 않으며 위치정보를 개발자 또는 개발자 운영 서버로 전송하지 않습니다. 사용자는 위치 권한을 허용하지 않고 도시를 직접 선택할 수도 있습니다.

3. 기도 알람 및 알림

알림 권한, 정확한 알람 접근 권한, 전체 화면 알람 기능, Wake Lock, 진동, 기기 재부팅 후 알람 복구 및 미디어 재생용 포그라운드 서비스는 사용자가 설정한 기도시간에 아잔을 예약·복구·표시·진동·재생하기 위해서만 사용됩니다.

이 기능들은 광고, 사용자 프로파일링 또는 분석 목적으로 사용되지 않습니다.

Privacy Policy — Muslim Korea

Effective date: November 15, 2026

Summary

Muslim Korea is an offline-first prayer utility. The current Android release does not require an account, does not show ads, and does not include developer-operated analytics or tracking. Prayer settings and location-based calculations are processed on the device.

1. Personal data collected

The current version of Muslim Korea does not collect or store user personal data on a developer-operated server and does not require registration or login.

2. Location

If the user chooses to use the current location, the app may request precise or approximate foreground location permission. Location is used on the device to calculate prayer times, determine the local time zone, resolve nearby city data, and calculate qibla direction.

The current Android release does not request background location and does not transmit location to the developer or a developer-operated server. Users may instead select a city manually.

3. Prayer alarms and notifications

Notification permission, exact-alarm access, full-screen alarm capability, wake lock, vibration, boot-completed handling, and a media-playback foreground service are used only to schedule, restore, display, vibrate, and play the adhan at prayer times configured by the user.

These capabilities are not used for advertising, profiling, or analytics.

4. Custom adhan audio

If the user selects custom adhan audio, Android's system file picker is used. The selected file is copied to the app's private storage for local playback and is not uploaded to a developer server.

5. Data stored locally on the device

The app may store language settings, location or city selection, prayer calculation settings, manual prayer-time adjustments, prayer alarm preferences, do-not-disturb settings, and imported custom audio locally on the device. The current release does not transmit this information to the developer.

6. Advertising and analytics

The current Android release does not include advertising SDKs, third-party advertising networks, developer-operated analytics SDKs, or user-tracking SDKs.

7. Network and third parties

The current Android release is designed to perform its core prayer calculations, city search, qibla calculation, and bundled adhan playback without a runtime Internet connection.

Google Play and the Android operating system may process store, device, crash, or security information under Google's own terms and privacy policies. That platform processing is separate from data collected by Muslim Korea.

8. Data retention and deletion

Because the current app does not operate user accounts or a developer-side user database, there is no server account to delete. Local settings and imported audio can be removed by clearing the app's storage or uninstalling the app.

9. Future changes

If a future release introduces network-based services, accounts, analytics, halal product search or commerce, or collection of user activity data, this Privacy Policy and the Google Play Data safety declaration will be updated before those features are released.
